# Jeep AA Diagnostic
Android application for investigating intermittent Android Auto Error 8 on Jeep Uconnect.
This is a diagnostic prototype, not a security-check bypass.
## Build
GitHub Actions > Build Android APK > Run workflow, then download artifact.
## Privacy
GPS coordinates and system logs may contain sensitive data. Keep exported logs private.
## Limitations
The app cannot read the Uconnect internal clock or guarantee visibility of Android Auto's protected logs.
